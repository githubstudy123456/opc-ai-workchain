## 6. 工具配置

| 层级 | 推荐选择 | 配置要点 |
| --- | --- | --- |
| 表单入口 | 飞书表单 / Airtable Form / Typeform | 必填字段、同意说明、来源追踪 |
| 数据底座 | 飞书多维表格 / Airtable / Google Sheets / PostgreSQL | 字段命名固定，保留时间戳和负责人 |
| 自动化编排 | n8n / Make / Zapier | 高风险步骤必须有人审或暂停节点 |
| AI 能力 | OpenAI Responses API / Agents SDK / 平台内置 AI | 明确工具权限、输入脱敏、输出结构化 |
| 通知审批 | Slack / 飞书 / 企业微信 / 邮件 | 审批人、超时提醒、驳回原因必填 |
| 归档 | Notion / 飞书文档 / GitHub / Drive | 版本号、交付物链接、验收记录 |

## 7. 提示词骨架

```text
你是一名一人公司 AI 自动化交付顾问。请基于以下客户资料，输出结构化项目简报。

约束：
1. 不承诺法律、税务、医疗、金融等专业结论。
2. 涉及外发消息、报价、合同、客户数据删除、生产系统写入时，必须标记为人工审批。
3. 输出必须包含：业务问题、成功指标、工作链步骤、输入输出、风险点、验收标准。
4. 信息不足时，不要编造，写入“待确认问题”。

客户资料：
{{lead_json}}

输出格式：
使用 Markdown，表格字段保持固定。
```
