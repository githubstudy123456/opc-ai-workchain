# 2026-06-12 一人公司 AI Agent 工作链与变现 SOP

> 适用对象：一人有限责任公司、个体工商户转公司、轻咨询/交付型 Solo Founder。  
> 检索日期：2026-06-12。  
> 本文不涉及 OPC UA / OPC Classic；OPC 指 One-Person Company / 一人公司。

## 1. 今日结论

| 主题 | 可执行判断 | 人工审批点 |
|---|---|---|
| 公司合规 | 一人公司必须把公司财产、个人财产、账户流水、合同主体和票据主体分开；否则在债务纠纷中容易触发股东连带责任风险。 | 每月由创始人复核银行流水、发票、合同主体、报销凭证。 |
| AI Agent | 现阶段适合做“半自动交付链”，不适合把报价、签约、付款、税务申报、客户承诺完全交给 Agent。 | 高风险动作必须人工确认：发报价、发合同、开票、付款、删库、外发客户数据。 |
| 低代码/无代码 | Zapier、Make 等平台适合 MVP；当流程涉及客户隐私、复杂异常分支、审计留痕时，应逐步迁移到自有脚本/API。 | 每个自动化上线前做 10 条历史样本回放。 |
| 变现路径 | 优先卖“固定场景 + 可验收结果”，例如线索清洗、竞品监控、日报生成、客服知识库、报价单初稿，而不是泛泛卖“AI 自动化”。 | 首单以 7 天试点交付；验收指标写入报价单。 |

## 2. 最小可售 AI 工作链

### 2.1 场景：B2B 获客到交付的一人公司流水线

| 阶段 | 输入 | AI/自动化动作 | 输出 | 失败处理 |
|---|---|---|---|---|
| 线索采集 | 行业关键词、目标城市、客群画像 | 搜索公开网页、企业黄页、招聘信息、公众号文章；抽取公司名、官网、联系人线索、痛点证据 | `leads.csv`，含来源链接和置信度 | 无来源链接的线索不得进入外联名单；低置信度进入人工复核 |
| 线索评分 | `leads.csv`、服务定位 | 按预算信号、痛点强度、近期事件、决策链可达性评分 | A/B/C 级线索 | A 级少于 20 条时扩大关键词，不直接群发 |
| 外联草稿 | 线索痛点、案例库、报价边界 | 生成 3 版短邮件/私信：诊断型、案例型、试点型 | 待审批外联文本 | 人工检查事实、称呼、行业术语和承诺边界 |
| 需求澄清 | 客户回复、会议纪要 | 摘要痛点、预算、时间线、成功标准、风险 | `brief.md` | 关键字段缺失时生成追问清单 |
| 方案报价 | `brief.md`、模板、成本表 | 生成方案、里程碑、交付物、验收标准、报价区间 | 报价单初稿 | 人工确认价格、周期、责任限制后才能发送 |
| 交付执行 | 客户资料、任务清单 | 建立看板、生成脚本/表格/提示词、产出日报 | 交付包、变更记录 | 客户资料不完整时暂停，发补料清单 |
| 复盘续费 | 验收记录、使用数据 | 生成 ROI 报告、续费建议、二期 backlog | 复盘报告和续费邮件 | ROI 不明显时改为维护包或培训包 |

### 2.2 推荐工具组合

| 预算 | 工具栈 | 适用场景 | 不适合 |
|---|---|---|---|
| 0-500 元/月 | 表格 + ChatGPT/Deep Research + 手动邮件 + GitHub Markdown | 验证服务定位、做首批案例 | 高并发、强权限控制 |
| 500-2000 元/月 | Airtable/Notion + Zapier/Make + OpenAI API + 飞书/钉钉 | 每月 3-10 个客户的小规模交付 | 涉及复杂审批、财务核心系统 |
| 2000 元/月以上 | 自有数据库 + 队列任务 + OpenAI Responses/Agents SDK + 审计日志 | 标准化产品化服务、SaaS 化试点 | 没有稳定需求前过早工程化 |

## 3. Agent 设计规范

### 3.1 六步执行协议

对所有能影响客户、钱、合同、数据的 Agent 动作，按下面协议设计工具，而不是直接给 Agent 一个“万能执行”接口：

| 步骤 | 工具动词 | Agent 必须返回 | 人工闸口 |
|---|---|---|---|
| 1 | `search` | 找到候选对象和来源 | 无 |
| 2 | `resolve` | 明确唯一对象、冲突项、置信度 | 置信度低于 0.8 时人工确认 |
| 3 | `preview` | 展示将要执行的变更、影响范围、回滚方式 | 涉及外发/付款/删除必须确认 |
| 4 | `execute` | 执行结果、事务编号、时间 | 高风险动作只能由人工触发 |
| 5 | `verify` | 验证证据、截图/链接/日志 | 无验证证据不得标记完成 |
| 6 | `recover` | 失败原因、重试策略、人工补救清单 | 连续失败 2 次后升级人工 |

### 3.2 Agent 系统提示词模板

```text
你是一人公司运营助理，只能在授权边界内处理任务。

目标：
- 帮创始人把获客、需求澄清、方案、交付、复盘流程标准化。
- 每一步都要保留来源、输入、输出、时间和人工审批记录。

禁止：
- 不得自行发送报价、合同、付款通知、发票信息或客户承诺。
- 不得编造来源、客户事实、政策条款、价格或案例。
- 不得把客户隐私数据发送到未授权工具。

输出格式：
1. 结论
2. 依据与来源
3. 待人工确认事项
4. 下一步动作
5. 风险与异常处理
```

### 3.3 上线验收标准

| 检查项 | 合格标准 |
|---|---|
| 数据来源 | 每条关键事实有 URL、文件名或客户原始输入引用 |
| 幻觉控制 | 随机抽查 20 条输出，事实错误不超过 1 条，且不能是价格/合同/政策类错误 |
| 审批链 | 外发、报价、合同、付款、开票、删除数据都有人工确认记录 |
| 异常恢复 | API 超时、权限失败、字段缺失、重复客户、客户退订均有分支处理 |
| 成本 | 每单 AI/API/自动化成本低于成交额 5%，试点期可放宽到 10% |
| 安全 | 客户数据按项目隔离；离职/结案后撤销共享权限 |

## 4. 一人公司合规清单

### 4.1 财产独立

| 动作 | 频率 | 留痕 |
|---|---|---|
| 公司收入只进公司账户，个人垫付走报销 | 每笔 | 银行流水、报销单、发票 |
| 合同、报价、发票主体一致 | 每单 | 合同 PDF、报价单、开票记录 |
| 个人消费不得从公司账户支付 | 每月 | 财务复核表 |
| 创始人借款、分红、工资分开记账 | 每月 | 借款协议、工资表、分红决议 |

### 4.2 税务关注点

| 项目 | 操作建议 | 风险 |
|---|---|---|
| 小规模/一般纳税人 | 关注年应税销售额、客户是否需要专票、进项抵扣需求 | 为省税长期不开票或虚开发票风险高 |
| 企业所得税 | 按真实成本费用、合同和发票归集利润 | 把个人支出混入公司费用会破坏财产独立 |
| 个税/社保 | 创始人工资、劳务、分红要区分 | 长期零工资但大量个人消费易被质疑 |
| 优惠政策 | 以财政部、税务总局最新公告和主管税务机关口径为准 | 地方执行口径可能不同 |

> 注意：本文是运营清单，不构成法律或税务意见；重大交易、股权、涉税事项应咨询律师/税务师。

## 5. 7 天试点产品设计

### 5.1 产品包：AI 获客雷达

| 模块 | 交付物 | 验收标准 |
|---|---|---|
| 客群定义 | ICP 表、关键词表、排除清单 | 客户确认 1 个主行业 + 2 个细分场景 |
| 线索抓取 | 100-300 条线索表 | 每条含来源链接；重复率低于 5% |
| 痛点证据 | 每家 1-3 条证据 | 证据来自官网、招聘、新闻、社媒或公开资料 |
| 外联话术 | 3 套邮件/私信模板 | 不承诺未验证结果；客户可直接使用 |
| 复盘建议 | A/B/C 级线索和下一步动作 | 至少给出 20 条优先联系名单 |

### 5.2 报价路径

| 阶段 | 价格 | 目标 |
|---|---:|---|
| 首次诊断 | 0-499 元 | 收集样本，验证客户是否有真实需求 |
| 7 天试点 | 1999-4999 元 | 交付可验证名单和外联资产 |
| 月度运营 | 8000-20000 元/月 | 每周更新线索、话术、复盘和自动化 |
| 内部系统搭建 | 30000 元起 | 为客户搭建自有半自动获客/交付链 |
