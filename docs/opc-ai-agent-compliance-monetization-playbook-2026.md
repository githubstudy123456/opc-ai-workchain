# 一人公司 AI Agent 合规与变现工作链 Playbook（2026）

> 适用对象：一人有限责任公司、个人独资/个体工商户升级中的一人经营团队、以 AI 自动化交付咨询/运营/内容/数据服务的小微企业。  
> 检索日期：2026-05-27。  
> 范围说明：本文中的 OPC 指 One-Person Company / 一人公司，不涉及 OPC UA 或 OPC Classic。

## 1. 先建立“可交付、可审计、可停机”的工作链

一人公司使用 AI agent 的核心风险不是“模型不会用”，而是无人复核时把获客承诺、客户数据、自动化动作和发票税务混在一起。建议把所有自动化拆成 6 个可审计节点：

| 节点 | 自动化目标 | 输入 | 输出 | 人工审批点 | 异常处理 | 验收标准 |
|---|---|---|---|---|---|---|
| 线索识别 | 从公开渠道筛选高匹配客户 | 行业、地区、客单价、痛点关键词 | 线索表、评分、来源链接 | 首次触达前确认名单合法性和话术 | 来源不明、个人敏感信息过多时丢弃 | 每条线索有公开来源、行业、痛点、触达理由 |
| 需求诊断 | 生成客户现状问卷和方案假设 | 客户网站、访谈纪要、业务目标 | 诊断报告、ROI 假设 | 报价前确认假设不夸大 | 信息不足时回到问卷补采 | 报告区分事实、推断、待确认项 |
| 方案报价 | 形成套餐、范围、里程碑 | 诊断报告、交付能力、成本 | SOW、报价单、交付日历 | 合同发送前人工审批 | 超范围需求进入变更单 | 范围、价格、付款、验收、变更规则清晰 |
| 自动交付 | 执行内容、表格、报表、工作流配置 | 客户授权、素材、API key | 初稿、配置记录、运行日志 | 对外发布/写入客户系统前审批 | 工具失败转人工队列 | 每次工具调用有日志、结果和回滚方式 |
| 质量验收 | 发现错误、幻觉、权限越界 | 交付件、日志、客户验收表 | 缺陷清单、修复记录 | 最终交付前审批 | 高风险错误触发暂停交付 | 关键数据可追溯，客户确认通过 |
| 复购转介绍 | 生成月报和下一步建议 | 运行数据、客户反馈 | 复盘报告、续费提案 | 发送续费方案前审批 | 指标未达成时先给补救方案 | 月报含效果、问题、下月动作 |

## 2. 合规底线：一人公司不是“无限自动化”

### 2.1 公司形态与责任隔离

2023 年修订的《中华人民共和国公司法》已于 2024-07-01 施行。公开解读中提到，新法放宽一人有限责任公司设立等限制，并允许设立一人股份有限公司。对一人公司而言，实务上仍要保留公司财产、个人财产、客户款项、税务票据和业务授权的边界。

执行清单：

| 项目 | 最低动作 | 证据留存 |
|---|---|---|
| 银行账户 | 公司收款走对公账户，个人垫付按报销单处理 | 银行流水、报销单、发票 |
| 合同主体 | 报价、合同、发票主体一致 | 合同、报价单、开票记录 |
| 授权边界 | 客户系统/API/素材使用需书面授权 | 授权邮件、SOW、账号权限截图 |
| 财产混同防控 | 不用个人账号长期托管客户资产 | 账号交接表、权限变更记录 |
| 决策记录 | 重大报价、退款、交付争议写入决策日志 | `decision-log.md` 或项目 CRM 记录 |

### 2.2 增值税与开票节点

2026-01-01 起《中华人民共和国增值税法》施行。税务机关在 2026 年发布了增值税优惠衔接与征管事项说明，其中小规模纳税人发生应税交易，销售额未达到起征点标准的，可以选择全部或部分应税交易放弃免税并开具增值税专用发票；小规模纳税人适用减按 1% 征收率政策时，应按 1% 征收率开具增值税发票。

自动化系统不要自动决定税务口径，只能做“提醒 + 资料归集 + 待会计确认”：

| 场景 | Agent 可自动做 | 必须人工/会计确认 |
|---|---|---|
| 客户要求专票 | 收集客户开票信息、合同、验收单 | 是否放弃免税、税率/征收率、开票时间 |
| 月度收入汇总 | 汇总订单、收款、退款、未开票金额 | 纳税申报表、优惠适用、跨期处理 |
| 平台收款 | 拉取平台账单并匹配订单 | 平台服务费抵扣、收入确认口径 |
| 退款/折让 | 生成红冲资料清单 | 红字发票、税务处理 |

## 3. 推荐工具架构：低代码接业务，Agent 做判断，日志做审计

| 层级 | 推荐能力 | 可选工具 | 配置要点 |
|---|---|---|---|
| 入口层 | 表单、邮件、IM、CRM | 飞书/企业微信/Notion/Airtable/HubSpot | 所有入口字段统一为客户、需求、授权、截止时间 |
| 编排层 | 触发器、分支、重试、人工审批 | Zapier、Make、n8n、Pipedream | 写入动作前设置 approval step；失败进人工队列 |
| Agent 层 | 诊断、生成、分类、总结、工具调用 | OpenAI Agents SDK、LangGraph、CrewAI | 限定工具权限；开启 tracing；敏感数据脱敏 |
| 数据层 | 客户资料、素材、交付记录 | Google Drive/OneDrive/Supabase/Postgres | 文件按客户/项目/日期归档；最小权限共享 |
| 审计层 | trace、日志、验收、变更 | OpenAI tracing、Zapier run history、GitHub Issues | 每个交付件能反查输入、提示词、审批人 |

OpenAI Agents SDK 文档说明，tracing 可以记录 agent run 中的 LLM generation、tool calls、handoffs、guardrails 和自定义事件。Zapier MCP 文档说明，MCP tools 是 AI client 可通过 Zapier 执行的具体 app actions。对一人公司来说，这两类能力应优先用于“可观察、可追责”的交付链，而不是直接放开写入客户系统。

## 4. 获客到交付 SOP

### 4.1 线索筛选提示词

```text
你是面向一人公司/小微企业的 B2B 自动化顾问。
任务：基于输入的公开公司信息，判断其是否适合购买“AI 自动化工作链诊断 + 首条流程落地”服务。

输入：
- 公司名称：
- 官网/店铺/社媒链接：
- 行业：
- 公开岗位/招聘/内容信号：
- 已知痛点：

输出 JSON：
{
  "fit_score": 0-100,
  "likely_pain": ["最多3条"],
  "automation_opportunity": ["最多3条，必须能在2周内验证"],
  "first_offer": "建议的低风险首单",
  "evidence_urls": ["公开来源链接"],
  "do_not_contact_reason": "如存在隐私、合规、来源不明或明显不匹配则填写"

限制：
- 不得编造公司事实。
- 没有公开证据时标记为待确认。
- 不处理个人敏感信息。
```

### 4.2 首单产品化套餐

| 套餐 | 价格锚点 | 交付周期 | 交付内容 | 不包含 | 复购路径 |
|---|---:|---|---|---|---|
| 诊断单 | 1,999-4,999 元 | 3-5 天 | 访谈、流程图、ROI 假设、工具选型 | 生产环境配置 | 转首条流程落地 |
| 首条流程落地 | 8,000-30,000 元 | 1-2 周 | 一个端到端自动化、审批点、日志、培训 | 大规模系统集成 | 月度运维 |
| 月度运维 | 3,000-20,000 元/月 | 持续 | 监控、优化、报表、异常处理 | 重大新流程 | 多流程扩展 |
| 行业模板授权 | 499-4,999 元/套 | 即交付 | SOP、提示词、表格、自动化蓝图 | 定制咨询 | 训练营/社群 |

### 4.3 交付流程

1. 收集客户授权：系统、素材、数据范围、发布权限。
2. 画出现状流程：触发条件、人工动作、工具、输出、失败点。
3. 标记风险等级：付款、合同、发票、个人信息、对外发布、客户系统写入。
4. 先做只读自动化：抓取、分类、汇总、草稿生成，不直接写入生产系统。
5. 设置人工审批：对外发送、开票、改客户数据、付款/退款、删除数据必须审批。
6. 小样本运行：至少 10 条历史记录回放，记录准确率、节省时间、失败原因。
7. 上线与回滚：保留手动流程入口，设置停机条件。
8. 月度复盘：按省时、增收、降错、客户满意度出报告。

## 5. 异常处理与停机条件

| 异常 | 自动处理 | 升级条件 | 停机条件 |
|---|---|---|---|
| 工具 API 失败 | 重试 2 次，写入失败队列 | 连续 3 次失败 | 影响客户生产数据 |
| 模型输出不确定 | 标记待确认，不进入写入动作 | 关键字段缺失 | 合同、发票、金额字段无法确认 |
| 客户数据越权 | 拒绝处理并记录 | 发现未授权数据 | 出现个人敏感信息或商业秘密外泄风险 |
| 对外内容风险 | 进入人工审核 | 涉及承诺收益、法律税务结论 | 客户未确认仍要求发布 |
| 税务口径不明 | 收集资料给会计 | 专票、红冲、跨期收入 | 自动化试图自行决定税率/优惠 |

## 6. 交付验收表

| 验收项 | 通过标准 | 证据 |
|---|---|---|
| 流程完整 | 从触发到输出全链路跑通 | Loom/截图/运行日志 |
| 准确率 | 样本测试达到合同约定阈值 | 测试表 |
| 审批点 | 高风险动作不能绕过人工确认 | 审批记录 |
| 可回滚 | 失败后能恢复手工流程 | 回滚说明 |
| 权限最小化 | Agent 只拥有必要工具和数据 | 权限截图 |
| 可维护 | 客户能按文档处理常见异常 | SOP 文档 |
