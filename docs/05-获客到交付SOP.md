# 获客到交付 SOP

## 阶段一：定位

一句话定位模板：

```text
我帮助【细分客户】把【高频重复流程】自动化，交付【可验证成果】，通常在【周期】内完成。
```

示例：

```text
我帮助本地教育机构把咨询线索、试听预约和课后跟进自动化，交付一套线索看板和自动提醒系统，通常 7 天内完成。
```

## 阶段二：获客

### 渠道

- 朋友圈、公众号、视频号、小红书、抖音、知乎。
- 行业社群。
- 本地商会、园区、联合办公空间。
- 朋友转介绍。
- GitHub、个人网站、案例页。
- 冷邮件或 LinkedIn。

### 内容选题

- 业务拆解：某行业 5 个最值得自动化的流程。
- 案例复盘：把 3 小时日报变成 10 分钟自动报告。
- 工具教程：用表单 + 表格 + AI 搭建客户跟进系统。
- 成本对比：请人、外包、买软件、自建自动化的区别。
- 风险提醒：AI 自动化最容易踩的 7 个坑。

## 阶段三：线索收集

表单字段：

- 姓名 / 公司
- 联系方式
- 行业
- 当前最耗时的流程
- 每周大约耗时
- 现有工具
- 预算范围
- 希望上线时间

自动处理：

- 写入线索表。
- AI 归类需求。
- 生成首次沟通问题。
- 高优先级线索推送提醒。

## 阶段四：诊断

诊断会议结构：

1. 业务目标：想提升收入、降低成本、减少错误还是加快响应？
2. 当前流程：从谁触发，到谁交付，中间经过哪些工具？
3. 数据来源：表格、后台、聊天记录、文档、API。
4. 风险点：隐私、权限、客户承诺、平台规则。
5. 成功指标：节省时间、响应速度、转化率、错误率、内容产量。

输出：

- 流程图。
- 自动化机会清单。
- 优先级排序。
- 报价方案。

## 阶段五：报价

报价结构：

- 背景问题
- 目标
- 工作范围
- 交付物
- 不包含内容
- 周期
- 客户需提供资料
- 验收标准
- 售后范围
- 价格和付款节点

三档报价：

| 档位 | 内容 | 适合客户 |
| --- | --- | --- |
| 诊断版 | 流程梳理 + 方案 | 不确定从哪里开始 |
| 搭建版 | 1 条完整工作链 | 有明确痛点 |
| 托管版 | 搭建 + 每月维护优化 | 想长期省心 |

## 阶段六：实施

实施清单：

- 创建项目编号。
- 创建客户文件夹。
- 收集资料和账号权限。
- 画流程图。
- 搭建数据表。
- 搭建自动化。
- 配置 AI 提示词和输出格式。
- 设置错误通知。
- 做 3 到 5 组测试。
- 写操作说明。

## 阶段七：验收

验收标准要可验证：

- 表单提交后是否自动入库。
- 是否能按规则分类。
- 是否能生成指定格式的草稿。
- 是否有人工审核步骤。
- 是否能推送给指定人员。
- 是否能归档记录。
- 出错时是否有提醒。

## 阶段八：复盘与复购

复盘问题：

- 节省了多少时间？
- 哪个步骤仍需人工？
- 输出质量是否稳定？
- 客户是否愿意继续付费维护？
- 能否复制给同类客户？

复购产品：

- 每月维护。
- 新工作链扩展。
- 数据报表。
- 内容运营。
- 员工培训。
- 知识库更新。
