# AI Agent 获客到交付治理 SOP（2026-06）

> 适用对象：一人公司 / 一人有限责任公司经营者，用 AI agent、低代码自动化和人工审批，把获客、售前、报价、交付、开票与复盘串成可追踪工作链。
>
> 检索日期：2026-06-15。本文不是法律、税务或投资意见；涉及注册资本、税务申报、劳动用工、广告合规、数据出境和行业资质时，应以主管机关、专业律师/会计师意见为准。

## 1. 可变现工作链

| 场景 | 客户痛点 | 可售卖交付物 | 首单价格锚点 | 复购路径 |
| --- | --- | --- | --- | --- |
| B2B 获客自动化 | 名单散落、跟进不及时、销售话术不一致 | 线索表、ICP 评分、首封邮件/私信、CRM 更新自动化 | 3000-15000 元/项目 | 每月线索清洗、内容外呼、CRM 看板维护 |
| 小微企业内容工厂 | 老板没时间持续发内容 | 选题库、短文案、海报 brief、发布日历、复盘表 | 2000-8000 元/月 | 月度内容运营 + 广告素材测试 |
| 交付文档自动化 | 需求记录、会议纪要、验收文档重复劳动 | 会议转写、需求摘要、风险清单、验收报告模板 | 3000-12000 元/项目 | 每个客户按项目/席位续费 |
| 财税/合规提醒助理 | 发票、合同、回款、纳税节点容易漏 | 合同台账、回款提醒、发票状态、月度资料包 | 1000-5000 元/月 | 与代账、法务、合同审查形成组合服务 |

## 2. 推荐架构

| 层级 | 工具/组件 | 输入 | 输出 | 人工审批点 |
| --- | --- | --- | --- | --- |
| 数据入口 | 表单、邮箱、企微/飞书/钉钉、CRM、Notion/Airtable | 线索、客户需求、会议纪要、合同草稿 | 标准化任务记录 | 首次接触客户、导入敏感数据前 |
| 编排层 | Zapier、Make、n8n、Pipedream 或自建 OpenAI Agents SDK | 触发器、业务规则、工具权限 | 跨应用任务流 | 新增写入型动作、外发消息动作 |
| Agent 层 | 研究 agent、销售 agent、交付 agent、质检 agent | 标准化任务记录 + 客户上下文 | 建议、草稿、待办、结构化 JSON | 报价、承诺交付期、法律/税务判断 |
| 审批层 | 人工 checklist、审批表、双确认按钮 | agent 输出和证据链接 | 批准/驳回/改写意见 | 所有不可逆动作 |
| 留痕层 | 日志、版本库、CRM 时间线、对象存储 | prompt、工具调用、输出、审批人 | 审计包、复盘数据 | 月度抽检、客户争议处理 |

## 3. 端到端 SOP

### 3.1 获客线索处理

1. 触发：表单提交、邮件到达、私域消息标星、公开目录新增企业。
2. Agent 读取：公司名、行业、职位、最近业务事件、可能痛点、联系方式来源。
3. 输出结构：

```json
{
  "company": "客户公司名",
  "persona": "老板/销售负责人/运营负责人",
  "pain_hypothesis": ["可能痛点1", "可能痛点2"],
  "fit_score": 0,
  "evidence_links": ["来源URL"],
  "first_touch_draft": "不超过120字的首触达文本",
  "approval_required": true
}
```

4. 人工审批：确认线索来源合法、痛点没有臆造、首触达不夸大承诺。
5. 自动动作：审批后写入 CRM，安排跟进提醒，发送首封邮件或生成企微待发送文案。
6. 异常处理：缺少来源链接时不得发送；联系方式来自非公开渠道时标记为 `blocked_privacy_review`。
7. 验收标准：每条外发信息可追溯到来源；CRM 字段完整率 >= 95%；被投诉率为 0。

### 3.2 售前诊断与报价

| 步骤 | Agent 任务 | 人工判断 |
| --- | --- | --- |
| 需求澄清 | 把客户描述拆成目标、当前流程、数据源、工具账号、约束 | 判断是否有真实预算和决策人 |
| 方案生成 | 给出 MVP 流程、工具清单、交付周期、风险点 | 删除不能保证的效果承诺 |
| 报价建议 | 按一次性搭建费、月度维护费、超量计费拆分 | 最终价格、付款节点、违约责任 |
| 合同资料 | 生成 SOW、验收标准、客户需配合事项 | 法务/会计师审阅关键条款 |

报价提示词：

```text
你是“一人公司 AI 自动化顾问”的售前助理。请只基于以下客户访谈记录生成报价建议：
1. 不承诺收入增长，只承诺可交付物和验收口径。
2. 把范围拆为 Must/Should/Could。
3. 每个自动化动作标注读取/写入/外发/付款/删除五类权限。
4. 所有写入、外发、付款、删除动作默认需要人工审批。
5. 输出：方案摘要、交付清单、排期、客户配合事项、风险、报价三档、验收标准。
客户访谈：
{{transcript}}
```

### 3.3 交付实施

1. 建立客户工作区：需求、凭证、账号权限、流程图、验收表分开存放。
2. 最小权限授权：优先使用测试账号、只读 API key、单独服务邮箱；禁止共用老板主账号密码。
3. 开发自动化：先做只读预览，再做写入草稿，最后接入审批后外发。
4. 设置 guardrails：
   - 输入校验：客户资料缺字段、包含密钥、包含身份证/银行卡等敏感信息时中止。
   - 输出校验：报价、税务、法律、医疗、金融建议必须标为“需人工复核”。
   - 工具校验：删除、付款、外发、批量更新 CRM 前必须二次确认。
5. 试运行：至少 20 条历史样本回放，记录误判、漏判、耗时、人工改写率。
6. 交付验收：客户在验收表勾选场景覆盖、字段准确、异常提醒、权限回收、培训完成。

## 4. Agent 角色与权限矩阵

| Agent | 允许 | 禁止 | 关键指标 |
| --- | --- | --- | --- |
| 研究 agent | 搜索公开资料、提取证据、生成摘要 | 伪造来源、抓取登录后资料 | 证据链接覆盖率、事实纠错率 |
| 销售 agent | 生成草稿、评分、CRM 草稿写入 | 自动承诺价格/折扣/交付期 | 回复率、人工改写率 |
| 交付 agent | 生成流程、脚本、配置说明、测试用例 | 直接操作生产数据批量变更 | 回放通过率、失败恢复时间 |
| 质检 agent | 检查敏感信息、验收项、SOW 范围 | 单独放行高风险动作 | 漏检率、阻断准确率 |
| 财务助理 agent | 整理发票、回款、资料包、提醒 | 替代会计师判断税种/税率 | 资料齐套率、逾期提醒率 |

## 5. 风险控制清单

| 风险 | 触发信号 | 控制措施 | 留痕材料 |
| --- | --- | --- | --- |
| 一人公司人格混同 | 公司与个人账户混用、合同主体混乱、费用无凭证 | 单独银行账户、合同/发票/收款主体一致、月度账务归档 | 银行流水、合同、发票、报销单 |
| 注册资本承诺过高 | 认缴额远高于业务现金流 | 按业务风险和出资能力设置，重大调整咨询专业人士 | 章程、股东决定、出资计划 |
| AI 幻觉 | 无来源结论、来源与结论不匹配 | 强制证据链接、事实字段置信度、人工抽检 | source log、review log |
| 数据泄露 | prompt 中含密钥、客户隐私、合同原文 | 脱敏、最小权限、禁止把密钥发给模型、工具 guardrail | 脱敏记录、权限列表 |
| 自动化误操作 | 批量删除、批量外发、批量改价 | 沙箱回放、二次确认、限速、回滚方案 | 测试报告、审批记录 |
| 夸大宣传 | “保证涨粉/保证成交/替代律师会计师” | 改为过程指标和交付物承诺 | 文案审批记录 |

## 6. 异常处理剧本

| 异常 | 立即动作 | 24 小时内 | 复盘修复 |
| --- | --- | --- | --- |
| 发错客户消息 | 停止同类自动化，人工联系客户说明 | 导出触发日志和审批记录 | 增加收件人校验、预览确认 |
| CRM 批量写错 | 冻结写入权限，备份当前状态 | 用最近备份或审计日志回滚 | 增加字段白名单和单批上限 |
| 输出包含敏感信息 | 删除外发草稿，标记事件 | 通知相关人员，检查来源 | 增加脱敏规则和输出 guardrail |
| 客户质疑结果 | 暂停验收，提供证据包 | 按 SOW 对照是否范围内 | 更新验收标准和样本集 |

## 7. 月度经营复盘表

| 指标 | 口径 | 目标 |
| --- | --- | --- |
| 线索到预约率 | 预约数 / 合格线索数 | >= 8% |
| 预约到成交率 | 新签客户 / 有效诊断会 | >= 20% |
| 毛利率 | (收入 - 外包 - 工具 - 模型成本) / 收入 | >= 60% |
| 自动化节省时间 | 人工原耗时 - 自动化后人工耗时 | 每客户每月 >= 5 小时 |
| 人工改写率 | 被人工大改的 agent 输出 / 总输出 | 前期 < 40%，稳定后 < 20% |
| 高风险动作审批率 | 已审批高风险动作 / 高风险动作 | 100% |
| 客户可验收交付率 | 通过验收项目 / 到期项目 | >= 90% |
