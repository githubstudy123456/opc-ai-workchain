# Playbook：内容生产自动化

## 目标

把客户定位、产品资料、案例和常见问题转化为可持续更新的内容日历和多平台内容。

## 流程

```text
客户资料库
  -> AI 提取卖点、案例、FAQ
  -> 生成选题池
  -> 人工筛选
  -> 生成大纲
  -> 生成初稿
  -> 事实核验
  -> 多平台改写
  -> 客户确认
  -> 发布或交付
  -> 数据复盘
```

## 内容类型

- 短视频脚本
- 小红书笔记
- 公众号文章
- LinkedIn 帖子
- FAQ
- 案例复盘
- 邮件营销

## AI 提示词

```text
你是 B2B 内容策略顾问。基于客户资料，为【目标客户】设计 30 天内容日历。
要求：
- 每天 1 个选题
- 标注平台：公众号 / 小红书 / 短视频 / LinkedIn
- 标注目标：获客 / 信任 / 教育 / 转化
- 每个选题给出一句核心观点
- 避免夸大承诺

输出表格。
```

## 质量检查

- 是否有事实来源。
- 是否符合客户行业语气。
- 是否避免绝对化用语。
- 是否包含明确行动指引。
- 是否符合平台规则。
