# Playbook：知识库问答系统

## 目标

把客户散落在文档、FAQ、客服记录和培训材料里的知识整理成可检索、可问答、可维护的知识库。

## 流程

```text
资料收集
  -> 去重和分类
  -> 生成摘要和标签
  -> 建立知识库目录
  -> 配置检索问答
  -> 设置不可回答边界
  -> 测试常见问题
  -> 人工验收
  -> 定期更新
```

## 资料分类

- 产品介绍
- 价格与套餐
- 售后政策
- 合同条款
- 常见问题
- 行业政策
- 内部培训
- 案例库

## 不可回答边界

机器人遇到以下情况应转人工：

- 涉及法律、医疗、金融、税务最终判断。
- 涉及客户投诉升级。
- 涉及退款、赔偿、合同变更。
- 知识库没有来源。
- 用户要求绕过规则。

## 验收指标

- 20 个常见问题命中率。
- 回答是否引用来源。
- 不知道时是否承认不知道。
- 是否能转人工。
- 是否有更新机制。
