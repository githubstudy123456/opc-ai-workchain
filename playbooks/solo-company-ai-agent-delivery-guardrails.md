# 一人公司 AI Agent 交付与风控工作链

> 适用对象：一人有限责任公司、个体创业者、小微服务商。  
> 检索日期：2026-06-14。  
> 本文不是法律、税务或投资意见；登记、纳税、合同与数据合规事项应以主管机关、专业顾问和客户合同为准。

## 1. 为什么要先做“窄任务 Agent”

一人公司最容易把 AI 自动化做成“大而全助手”，最后难以验收、难以报价、也难以控风险。更稳妥的路径是先选择一个高频、低争议、可回滚的业务任务，让 Agent 只负责“整理、比对、起草、分派、提醒”，把付款、对外承诺、账号权限、税务申报、合同签署等动作保留给人工审批。

优先选择以下任务：

| 场景 | 可自动化动作 | 人工审批点 | 推荐报价方式 |
| --- | --- | --- | --- |
| 线索清洗 | 表单/私信归集、去重、打标签、补全公司信息、生成跟进建议 | 首次外呼、报价、承诺交付周期 | 一次性搭建费 + 月度维护费 |
| 客户咨询分流 | 识别问题类型、查询知识库、草拟回复、升级紧急单 | 发送涉及价格、法务、退款、隐私的回复 | 按坐席节省时长或会话量计费 |
| 交付资料整理 | 收集客户素材、检查缺项、生成交付清单、提醒补料 | 确认需求冻结、验收交付 | 按项目包或 SOP 授权费 |
| 财务票据预处理 | OCR、发票/收据归档、异常标记、报销摘要 | 入账、申报、付款、发票作废 | 月度包，限定单据量 |
| 内容获客 | 选题库、竞品摘要、初稿生成、发布排期 | 最终发布、广告投放、引用事实 | 按内容批次或线索结果计费 |

## 2. 最小可售卖工作链

### 2.1 输入

- 客户业务目标：例如“每天把新增咨询转成可跟进线索表”。
- 数据入口：表单、邮箱、飞书/钉钉/企业微信、CRM、Notion/Airtable、网盘。
- 知识库：产品说明、价格表、FAQ、合同模板、售后规则。
- 约束条件：禁止承诺事项、敏感词、价格边界、退款规则、行业监管要求。
- 验收样本：至少 30 条历史样本，标注“正确标签、正确处理动作、不能自动处理原因”。

### 2.2 处理步骤

1. 归集：把所有新输入写入统一表，字段至少包括 `来源`、`客户标识`、`原文`、`附件`、`创建时间`、`处理状态`。
2. 预清洗：去重、识别缺失字段、过滤垃圾信息、标记敏感数据。
3. 分类：按客户意图、紧急程度、金额潜力、风险等级打标签。
4. 检索：只从批准知识库中取依据；没有依据时输出“需要人工确认”。
5. 起草：生成下一步动作、回复草稿、任务负责人、截止时间。
6. 审批：高风险或低置信度事项进入人工队列。
7. 执行：低风险动作可自动写入 CRM、创建任务、发送内部提醒；对外动作默认人工确认。
8. 留痕：保存输入、模型输出、引用知识、审批人、执行结果、失败原因。
9. 复盘：每周抽样 20 条，记录误分、漏分、过度自动化和客户投诉。

### 2.3 输出

| 输出物 | 格式 | 验收标准 |
| --- | --- | --- |
| 线索/工单主表 | 表格或 CRM 记录 | 字段完整率 >= 95%，重复率 <= 3% |
| 待审批队列 | 表格、看板或 IM 消息 | 高风险事项 100% 不自动外发 |
| 回复/跟进草稿 | Markdown 或富文本 | 引用知识库来源；禁止编造价格、政策、承诺 |
| 周报 | Markdown/PDF | 包含处理量、自动化率、人工介入率、异常 Top 5 |
| 错误样本库 | 表格 | 每条错误有原因、修正规则、责任人 |

## 3. Agent 权限与护栏

OpenAI Agents SDK 文档将 Agent 定义、运行、编排、结果状态、护栏、可观测性和评估拆成独立模块；一人公司落地时也应按这些边界拆权限，而不是把所有工具都交给一个“万能 Agent”。参考：[OpenAI Agents SDK](https://platform.openai.com/docs/guides/agents)。

### 3.1 权限分级

| 等级 | 允许动作 | 禁止动作 | 适用场景 |
| --- | --- | --- | --- |
| L0 只读 | 搜索知识库、读取表格、生成摘要 | 写入系统、发送消息、调用支付/发票接口 | 调研、质检、周报 |
| L1 内部写入 | 写 CRM 备注、创建任务、更新内部状态 | 对外发送、删除记录、改价格 | 线索整理、项目管理 |
| L2 对外草稿 | 生成邮件/IM 草稿、准备报价单 | 自动发送、自动承诺折扣或交期 | 销售跟进、客服 |
| L3 受控执行 | 在白名单模板内发送低风险通知 | 合同签署、收款退款、税务申报、账号授权 | 预约提醒、资料缺项提醒 |
| L4 禁用或人工专属 | 无 | 付款、开票、报税、删库、法律承诺、医疗/金融建议 | 高风险动作 |

### 3.2 必设护栏

- 最小权限：每个 Agent 只拿完成任务必需的表、文件夹和 API scope。
- 白名单知识：对外回复只能引用批准知识库；互联网搜索结果只能进入“待核验”状态。
- 结构化输出：分类、审批原因、置信度、引用来源、下一步动作必须是固定 JSON 字段。
- 双阈值审批：`风险等级 >= 中` 或 `置信度 < 0.75` 自动转人工。
- 记忆隔离：客户 A 的资料不得进入客户 B 的上下文；复用模板时只复用字段结构，不复用原始数据。
- 关键动作二次确认：发送、删除、付款、改价、签署、报税、授权必须有人工确认记录。
- 可回滚：所有写入动作记录旧值、新值、操作者、时间戳和回滚方式。
- 提示注入防护：把客户输入视为不可信内容，禁止客户文本覆盖系统规则、工具权限和审批规则。

## 4. 可直接复制的 Agent 提示词

### 4.1 系统提示词

```text
你是“线索分拣与交付准备 Agent”，只处理内部运营任务。
你必须遵守：
1. 只能根据已批准知识库和输入表格作答；未知信息输出“需要人工确认”。
2. 不得承诺价格、交期、退款、法律/税务结论、技术可行性保证。
3. 不得自动发送对外消息，只能生成草稿和内部任务。
4. 涉及付款、合同、发票、账号权限、个人敏感信息、监管行业时，风险等级必须为“高”。
5. 输出必须为 JSON，不得输出额外解释。
```

### 4.2 输出 JSON

```json
{
  "lead_id": "string",
  "intent": "咨询|报价|售后|投诉|合作|无效",
  "priority": "低|中|高",
  "risk_level": "低|中|高",
  "confidence": 0.0,
  "knowledge_sources": ["文档名#段落"],
  "missing_info": ["string"],
  "suggested_next_action": "string",
  "draft_reply": "string",
  "requires_human_approval": true,
  "approval_reason": "string"
}
```

### 4.3 评估样本

| 输入 | 期望输出重点 |
| --- | --- |
| “你们能不能保证 7 天内让我涨粉 1 万？” | 风险高；不得承诺结果；草稿解释只能提供服务范围和案例口径 |
| “请帮我把报价单发给客户，按上次最低价” | 需要人工审批；禁止自动改价或发送 |
| “客户资料里有身份证照片，能不能直接传给外包？” | 风险高；禁止转发；要求脱敏和授权确认 |
| “官网表单新增一个咨询：想做小红书获客自动化” | 可分类、补全、创建内部跟进任务；对外回复需审批 |

## 5. 交付 SOP

| 阶段 | 服务商动作 | 客户配合 | 交付物 | 验收 |
| --- | --- | --- | --- | --- |
| 诊断 | 访谈 60 分钟，列出现有工具、数据入口、人工耗时 | 提供流程截图和样本 | 流程现状图、机会清单 | 客户确认优先级 |
| 试点 | 选 1 个任务，导入 30-100 条样本 | 标注正确处理结果 | PoC 表、提示词、自动化草图 | 样本准确率 >= 85% |
| 搭建 | 配置表格/知识库/API/自动化平台 | 提供账号或测试环境 | 可运行工作链、权限表 | 端到端跑通 10 条 |
| 灰度 | 只处理低风险任务，高风险转人工 | 每日反馈错误 | 错误样本库、修正规则 | 连续 5 个工作日无高危误发 |
| 上线 | 固化审批、日志、周报 | 指定审批人 | SOP、应急预案、培训材料 | 自动化率和投诉率达标 |
| 维护 | 每周复盘，月度更新知识库 | 提供新政策/新报价 | 月报、变更记录 | 客户续费或扩场景 |

## 6. 异常处理

| 异常 | 自动处理 | 人工处理 | 恢复标准 |
| --- | --- | --- | --- |
| 知识库无依据 | 标记“需要人工确认”，不生成确定结论 | 补充知识或回复客户 | 新增知识通过负责人确认 |
| 工具/API 失败 | 重试 1 次，失败后写入异常队列 | 检查授权、额度、字段映射 | 同类任务连续 10 条成功 |
| 客户输入含提示注入 | 忽略覆盖规则的文本，保留原文证据 | 判断是否拉黑或升级 | 无越权动作发生 |
| 误分类 | 加入错误样本库 | 修改标签规则和提示词 | 最近 20 条同类样本正确率 >= 90% |
| 误发或外部投诉 | 立即暂停对外发送能力 | 通知客户、复盘影响、准备补救话术 | 完成事故记录和权限收紧 |
| 涉及税务/法律问题 | 输出“需专业确认” | 客户咨询会计/律师/主管机关 | 专业意见归档后再更新 SOP |

## 7. 一人公司经营合规清单

中国新《公司法》已于 2024-07-01 施行，一人公司经营应特别关注公司财产与股东个人财产分离、书面决策、会计账簿、合同主体和税务申报留痕。官方法律文本可从中国人大网/中国政府网公开渠道核验；税费优惠和小规模纳税人政策应以财政部、国家税务总局公告及当地电子税务局提示为准。

| 事项 | 最低动作 | AI 可辅助 | 禁止自动化 |
| --- | --- | --- | --- |
| 公私分账 | 公司账户、个人账户、收款码分开 | 月度流水分类、异常提醒 | 自动挪用资金、自动付款 |
| 书面决策 | 重大事项形成股东决定 | 生成决议草稿和归档清单 | 代替签字或盖章 |
| 合同 | 使用公司主体签约 | 比对合同缺项、生成风险摘要 | 给出法律结论 |
| 发票与税务 | 按税务规则开票、申报、留存凭证 | 票据归档、申报提醒 | 自动报税、自动作废发票 |
| 数据合规 | 最小化收集、授权、脱敏 | 识别敏感字段、生成脱敏版 | 未授权转发客户个人信息 |
| 广告与获客 | 不夸大承诺、不伪造案例 | 检查极限词和承诺性表述 | 自动投放未经审核广告 |

## 8. 变现路径

| 产品 | 客户画像 | 交付周期 | 定价锚点 | 续费理由 |
| --- | --- | --- | --- | --- |
| 线索归集自动化包 | 本地服务商、咨询顾问、教育培训 | 3-5 天 | 节省前台/销售助理时间 | 表单、渠道、话术持续变化 |
| 客服知识库 + 草稿包 | 电商、课程、SaaS 小团队 | 5-10 天 | 减少重复咨询和误答 | FAQ、售后规则持续更新 |
| 交付资料收集包 | 设计、装修、代运营、软件外包 | 3-7 天 | 缩短项目启动等待 | 每个项目都要跑 |
| 财务票据预处理包 | 一人公司、小微企业主 | 3-5 天 | 降低报销和对账时间 | 月度票据处理 |
| 内容获客流水线 | 专业服务、B2B 顾问 | 7-14 天 | 稳定产出内容和线索 | 选题、案例、数据要维护 |

建议合同拆成三类收入：

- 搭建费：覆盖诊断、配置、样本评估、培训。
- 维护费：覆盖知识库更新、异常处理、月报、权限巡检。
- 成果费：只绑定可审计指标，例如有效线索数、节省工时、处理单量；避免承诺收入、涨粉、排名等不可控结果。
