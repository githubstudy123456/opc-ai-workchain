# Playbook：客户线索自动跟进

## 目标

把来自表单、私信、邮箱和社群的潜在客户统一进入线索表，并自动完成分类、提醒、首次回复和跟进任务。

## 输入

- 客户姓名
- 联系方式
- 行业
- 需求描述
- 预算
- 期望上线时间
- 来源渠道

## 流程

```text
客户提交表单
  -> 写入线索表
  -> AI 判断行业、需求类型、优先级
  -> 自动发送确认消息
  -> 高价值线索推送到手机
  -> 创建跟进任务
  -> AI 生成首次沟通问题
  -> 人工沟通
  -> 根据纪要生成报价草案
```

## AI 提示词

```text
你是小微企业自动化顾问。请根据以下客户信息判断：
1. 客户行业
2. 需求类型
3. 紧急程度：高 / 中 / 低
4. 是否适合 15 分钟诊断
5. 首次沟通要问的 5 个问题

输出 JSON：
{
  "industry": "",
  "need_type": "",
  "priority": "",
  "fit": true,
  "questions": []
}
```

## 人工审核点

- 是否真实客户。
- 是否有预算。
- 是否属于高风险行业。
- 是否有明显不合法需求。

## 交付指标

- 首次响应时间小于 10 分钟。
- 每条线索都有状态。
- 高价值线索不漏跟。
- 每周能统计来源和转化率。
